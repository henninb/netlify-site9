# netlify-site9

A Vue.js (Vite) navigation dashboard linking to all bhenning.com / brianhenning.com sites. Deployed to `site9.bhenning.com`.

## Tech Stack

- Vue 3 (Composition API, `<script setup>`)
- Vite
- Netlify deployment

## Features

- Dashboard grid with links to all nine sites using a `SiteCard` component
- Dynamically resolves the base domain

## Setup

```bash
npm install
```

## Running

```bash
./run.sh
```

## Build

```bash
npm run build
```

## Deployment

Deploys to Netlify via `netlify.toml`.
